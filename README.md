# 교재 공동 편집 시스템

여러 명이 브라우저에서 마크다운 교재 원고를 함께 편집하는 도구. 서버 없이 GitHub Pages + GitHub API 만으로 동작한다.

**편집기 주소** — https://sjmoon0621.github.io/markdown-editor/

## 저장소 구성

| 저장소 | 공개 | 내용 | GitHub Pages |
|--------|------|------|--------------|
| `markdown-editor` (이 저장소) | **Public** | 편집기 웹앱 (HTML·CSS·JS, 빌드 불필요) | **켬** |
| `integrated-science-content` | **Private** | 교재 원고 `.md` 31개 + `attachments/` 이미지 | 끔 |

무료 플랜에서는 비공개 저장소에 Pages 를 켤 수 없다. 그래서 앱만 공개 저장소에 두고,
원고는 비공개 저장소에 두어 브라우저가 GitHub API 로 직접 읽어온다.
**원고는 앱에 포함되지 않으므로, 사이트에 접속해도 본인 토큰이 없으면 아무것도 보이지 않는다.**

- [tools/collect-images.sh](tools/collect-images.sh) — 옵시디언 볼트에서 원고가 참조하는 이미지를 모아오는 스크립트

## 설치

[SETUP.md](SETUP.md) 에 저장소 만들기부터 편집자 초대까지 단계별로 정리되어 있다.

## 권한 모델

편집 권한 = 비공개 저장소의 **Collaborator** 목록. GitHub이 직접 검사하므로 앱을 우회할 수 없다.
각 편집자는 fine-grained personal access token 을 한 번 발급해 브라우저에 저장한다.
토큰은 브라우저 `localStorage` 에만 있고 GitHub 외의 어디로도 전송되지 않는다.

## 주요 기능

- 좌우 분할 편집 + 실시간 미리보기, 스크롤 동기화
- 옵시디언 문법: `![[이미지|400]]`, `[[위키링크]]`, `==하이라이트==`, `> [!callout]`, `$수식$`, `%%주석%%`
- 이미지 붙여넣기·드래그 업로드 → `attachments/` 에 커밋되고 `![[파일명]]` 자동 삽입
- **PDF 내보내기** — 전체 31개 문서를 한 파일로. A4 조판, **쪽 번호는 맨 아래 가운데**,
  표지와 실제 쪽 번호가 들어간 목차, 단원마다 새 페이지. (Paged.js + 브라우저 인쇄)
- 파일명·본문 통합 검색
- 원격 변경 감지(45초)와 저장 충돌 해결 (사본 저장 / 덮어쓰기 / 되돌리기)
- 미저장 내용 브라우저 임시저장, 변경 이력 조회 및 복원
- 라이트/다크 테마

## 로컬에서 열어보기

```bash
cd app && python3 -m http.server 8000
# http://localhost:8000
```

## 옵시디언과 병행

원고 저장소를 `git clone` 한 폴더를 옵시디언 볼트로 열면 된다.
작업 전 `git pull`, 작업 후 `git push`. 웹 편집기와 같은 저장소를 보므로 내용이 공유된다.
