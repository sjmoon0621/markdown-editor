교재 편집기

GitHub 계정으로 원고를 편집합니다. 저장소 협업자로 등록된 사람만 편집할 수 있습니다.

토큰은 어떻게 만드나요?
  1. GitHub → 우측 상단 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token 클릭
  4. Repository access → Only select repositories → 콘텐츠 저장소 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로 설정
  6. 만료일(Expiration)은 원하는 기간으로 (최대 1년)
  7. 생성된 토큰을 복사해 위 칸에 붙여넣기

토큰은 이 브라우저에만 저장되며 서버로 전송되지 않습니다.
